# Изменения

## 0.1.0 (в разработке)

Первая версия пакета. Основана на скриптах `pack_shards.py`, `analyze_workdir.py`, `compare_zip.py` и `check_hf_upload.py`.

- Одна команда `shardkeep` с подкомандами `analyze`, `pack`, `verify`, `unpack`, `upload`, `check-upload`, `check`, `card`, `compare-zip`.
- Формат архивов 2: параметры каждой части в `.meta.json`, полнота набора, файлы, не прочитанные при упаковке. Архивы исходного скрипта читаются и продолжаются, исходный скрипт читает новые архивы.
- Профили сжатия и выбор уровня по содержимому, число потоков по свободной памяти.
- `pack` больше не перезаписывает карточку датасета. `card` обновляет только части между метками.
- Условия лицензии больше не встроены в код: лицензия задается файлом.
- Правила анализатора вынесены в TOML.
- Загрузка в Hugging Face и через rclone с продолжением и сверкой по SHA-256.
- Необязательный перевод JPEG в JPEG XL без потерь.
- Отдельный скрипт восстановления для Python 3.8+.
- Сообщения программы на английском, документация на русском и английском.
- Строка прогресса с оценкой оставшегося времени у всех долгих операций; `--no-progress` отключает ее.
